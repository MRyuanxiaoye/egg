# 大乐透走势图分析系统架构

## 系统概述

本系统实现了基于走势图匹配的大乐透号码预测方法，核心思路是通过图论和机器学习"看懂"走势图，匹配最合适的号码组合。

## 核心设计理念

### 1. 横向分析（位置走势）
```
每个位置的号码走势：
前区位置1: [1, 3, 5, 4, 6, ...]  ← 位置1的号码变化
前区位置2: [8, 10, 9, 11, 12, ...]  ← 位置2的号码变化
前区位置3: [15, 17, 16, 18, 19, ...]  ← 位置3的号码变化
前区位置4: [22, 24, 23, 25, 26, ...]  ← 位置4的号码变化
前区位置5: [30, 32, 31, 33, 34, ...]  ← 位置5的号码变化
后区位置1: [2, 4, 3, 5, 6, ...]  ← 后区位置1的号码变化
后区位置2: [8, 10, 9, 11, 12, ...]  ← 后区位置2的号码变化
```

### 2. 纵向分析（组合走势）
```
整个号码组合的特征走势：
和值走势: [85, 92, 88, 95, 90, ...]  ← 每期和值变化
跨度走势: [28, 30, 29, 31, 27, ...]  ← 每期跨度变化
奇偶比走势: [3, 2, 3, 2, 4, ...]  ← 每期奇偶比变化
大小比走势: [2, 3, 2, 3, 1, ...]  ← 每期大小比变化
```

### 3. 走势图可视化
生成折线图展示：
- 每个位置的号码走势（横向）
- 组合特征的走势（纵向）
- 综合走势图（所有位置叠加）

### 4. 机器学习"看懂"走势图
- **LSTM**: 学习时间序列的长期依赖
- **Transformer**: 学习位置之间的关系
- **CNN**: 从图像中提取视觉特征

### 5. 模式匹配
找到与当前走势最相似的历史模式，基于相似模式进行预测。

## 核心类说明

### TrendAnalyzer
**功能**: 走势图分析核心类

**主要方法**:
- `get_position_trends()`: 获取位置走势（横向）
- `get_combination_trends()`: 获取组合走势（纵向）
- `generate_trend_images()`: 生成走势图
- `extract_trend_features_for_ml()`: 提取ML特征

### TrendMLPredictor
**功能**: 机器学习预测器

**支持的模型**:
- `PositionLSTM`: LSTM模型，学习时间序列
- `TrendTransformer`: Transformer模型，学习位置关系
- `TrendCNN`: CNN模型，从图像提取特征

**工作流程**:
1. 准备训练数据（特征+目标）
2. 训练模型
3. 使用模型预测

### TrendMatcher
**功能**: 模式匹配器

**工作流程**:
1. 构建历史模式库
2. 计算当前模式与历史模式的相似度
3. 找到最相似的模式
4. 基于相似模式进行预测

### TrendBasedPredictor
**功能**: 走势预测主类（整合所有功能）

**主要方法**:
- `analyze_trends()`: 综合分析走势
- `train_ml_model()`: 训练ML模型
- `predict_by_trend_matching()`: 模式匹配预测
- `predict()`: 综合预测（支持多种方法）

## 使用流程

### 1. 数据准备
```python
data = pd.read_csv('lottery_history.csv')
# 格式：期号,前区1,前区2,前区3,前区4,前区5,后区1,后区2
```

### 2. 初始化预测器
```python
predictor = TrendBasedPredictor(
    data=data,
    use_ml=True,      # 是否使用机器学习
    model_type='lstm' # 模型类型
)
```

### 3. 走势分析
```python
trends = predictor.analyze_trends()
# 输出横向和纵向走势分析
```

### 4. 生成走势图
```python
image_paths = predictor.generate_trend_report()
# 生成所有走势图PNG文件
```

### 5. 训练模型（可选）
```python
predictor.train_ml_model(epochs=50)
```

### 6. 预测
```python
# 方法1：模式匹配
front, back = predictor.predict_by_trend_matching()

# 方法2：机器学习
front, back = predictor.ml_predictor.predict()

# 方法3：集成（推荐）
front, back = predictor.predict(method='ensemble')
```

## 预测策略对比

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 模式匹配 | 简单直观，无需训练 | 可能过度依赖历史 | 数据量中等 |
| LSTM | 学习时间依赖 | 需要大量数据 | 数据量充足 |
| Transformer | 学习位置关系 | 计算复杂度高 | 需要捕捉位置关系 |
| 集成方法 | 稳健，降低风险 | 计算复杂 | 追求稳健性 |

## 技术特点

- 分析每个位置的独立走势
- 理解位置之间的关联性
- 预测每个位置的下一期值

### 2. 纵向分析
- 分析组合的整体特征
- 理解组合特征的变化规律
- 预测组合特征的下期值

### 3. 图论应用
- 将走势视为图结构
- 分析节点（位置）之间的关系
- 识别图模式

### 4. 机器学习
- 深度学习模型学习复杂模式
- 自动特征提取
- 非线性关系建模

### 5. 模式匹配
- 相似度计算
- 历史模式检索
- 基于相似性的预测
